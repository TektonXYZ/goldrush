# GoldRush

A Wild West gold-mining tycoon in full 3D.

## The idea

Stake a claim, dig a mine and grow a frontier town. You walk the surface in first person, go underground to work the veins, and run the business from an old computer in your office: buy machines, ship ore and race horses against other players.

## Main screens

- Title and tutorial
- The surface: town, land office and claims
- The mine: veins, carts and machines
- The office computer: shop, exchange, leaderboard and races
- Horse races

Front end only. The backend, wallets and live data are not in this repo, and every address is a placeholder.

## Run it

```
npm install
npm run dev
```

Live site: https://thegoldrush.fun
